# 机床智能助手（Machine Tool Assistant）

基于 [Mastra](https://mastra.ai) + [Next.js](https://nextjs.org)（App Router）构建的机床领域 AI 智能助手。

## 快速开始

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看效果。

## 环境变量

在项目根目录创建 `.env.local`：

```env
ZHIPU_API_KEY=你的智谱API Key
```
